# sake-collection

毎週1本ずつ購入するお酒のコレクションを管理する Web アプリです。`index.html` 1ファイルで完結し、ビルドは不要です。

- データはブラウザ内の IndexedDB に保存されます（端末・ブラウザごとに別管理）
- 写真はアップロード時に長辺1200px・JPEG品質0.8へ自動で縮小してから保存します
- ⚙メニューから JSON（写真を含む）／CSV（写真なし）の書き出しと、JSON の読み込み（上書き／追加）ができます
- サンプルデータは ⚙メニューから投入でき、「サンプルのみ削除」で一括削除できます（No. の採番には影響しません）

## 使い方

- ローカル：`index.html` をダブルクリックしてブラウザで開きます
- 公開：GitHub Pages（Settings → Pages → Deploy from a branch → `main` / `(root)`）で公開します

> データはブラウザごとに保存されます。機種変更やブラウザのデータ削除に備えて、定期的に JSON エクスポートでバックアップを取ってください。
