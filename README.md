# sake-collection

毎週1本ずつ購入するお酒のコレクションを管理する Web アプリです。`index.html` で完結し、ビルドは不要です（オフライン起動用の `sw.js` を同じ場所に置きます）。

## データの保存と同期（Firebase）

- メールアドレスとパスワードでログインすると、データは Firebase（Cloud Firestore）に保存され、スマートフォンとPCで自動的に同期されます
  - ログイン状態は端末に保存されるので、毎回ログインする必要はありません（⚙メニューからログアウトできます）
  - アプリ内に新規登録画面はありません。ユーザーは Firebase コンソールの Authentication で作成してください
- 電波がない場所でも登録・編集できます。電波が戻ると自動で同期されます（画面上部に「同期済み／同期中／オフライン」を表示）
- Firestore の構成
  - `users/{uid}/bottles/{id}` … お酒の記録。一覧用の軽量サムネイル（長辺360px）を含む
  - `users/{uid}/photos/{id}` … 写真本体（Base64・1枚1ドキュメント）。長辺1200px・JPEG品質0.8で圧縮し、900KBを超える場合は品質や解像度を下げて再圧縮します。拡大表示のときだけ読み込みます
  - `users/{uid}/meta/counter` … No. の採番カウンタ
- Firestore のルールは `users/{uid}/{document=**}` を本人のみ読み書きできるように設定してください
- 以前のバージョン（端末内の IndexedDB に保存）のデータがある端末では、ログイン後に「クラウドへ移行しますか？」と表示されます。⚙メニューの「この端末のデータをクラウドへ移行」からも実行できます（端末内のデータは移行後も削除されません）

## 銘柄情報の自動登録（imports/）

- Claude Code に銘柄名と購入情報を伝えると、Web で調べた情報を `imports/YYYYMMDD-HHMM-<スラッグ>.json` として作成し、`imports/index.json` に登録します（作業ルールは CLAUDE.md）
- アプリはログイン後と、開き直したときに `imports/index.json` を確認し、未取り込みのデータがあれば「新しい登録データがN件あります」と表示します（⚙メニューの「新しい登録データを確認」からも確認できます）
- 取り込みは JSON インポートの「追加」と同じ扱いで、No. は続きから採番されます。取り込み済みのファイル名は Firestore の `users/{uid}/meta/imports` に記録されるので、他の端末で二重に取り込まれることはありません
- 写真のない記録には一覧に「写真未登録」と表示されます。実物を撮影して編集画面から追加してください
- 登録データの検証：`node tools/check-imports.mjs`

## 分類（種別 → 大分類 → 小分類）

- 種別（プルダウン）→ 大分類（種別に応じて切り替わるプルダウン）→ 小分類（候補付きの自由入力）の3階層です。大分類・小分類は未選択でも保存できます
- 一覧・カードには「ウイスキー／スコッチ／シングルモルト」のようにつなげて表示し、「大分類」で絞り込めます。集計の「種別ごとの本数と金額」は、種別をタップすると大分類ごとの内訳が開きます
- 以前の「種別＋サブ種別」で登録した記録は、ログイン後に自動で振り分けた案が表示され、確認・修正して［確定］で一括反映できます（⚙メニュー「分類の移行」からも開けます）。旧サブ種別の値は `legacySubCategory` として残ります
- 分類の定義は index.html の `TAXONOMY` にあります

## 閲覧用リンクの共有

- ⚙メニュー「閲覧用リンクの共有」でオンにすると、ログインなしで閲覧できるリンク（`…/?view=<uid>~<合言葉>`）が発行されます
- リンクを開いた人は一覧・集計・写真を見られますが、追加・編集・削除はできません（Firestore のルールで書き込みを禁止）
- 登録・編集の内容はリンク先にもリアルタイムで反映されます。オフにするとすぐに閲覧できなくなり、「リンクを作り直す」で古いリンクを無効にできます
- 利用には Firebase コンソールで次の設定が必要です
  1. Authentication → Sign-in method → 「匿名」を有効にする（閲覧者は匿名ログインで閲覧します）
  2. Firestore Database → ルール に、リポジトリの `firestore.rules` の内容を貼り付けて公開する

## 表示言語

- ⚙メニュー（またはログイン画面）で日本語／English を切り替えられます（端末ごとに保存）
- 保存する値は日本語のままで、表示だけを切り替えます。銘柄名やメモなど、入力した文字はそのまま表示されます

## その他の機能

- ⚙メニューから JSON（写真を含む）／CSV（写真なし）の書き出しと、JSON の読み込み（上書き／追加）ができます（大分類・小分類・旧サブ種別も含みます。旧形式のバックアップも読み込めます）
- サンプルデータは ⚙メニューから投入でき、「サンプルのみ削除」で一括削除できます（No. の採番には影響しません）

## 使い方

- GitHub Pages（Settings → Pages → Deploy from a branch → `main` / `(root)`）で公開して使います
  - Firebase を使うため、`index.html` をダブルクリックして開く方法（file://）には対応していません
- iPhone では Safari で開いて「共有 → ホーム画面に追加」するとアプリのように使えます（ホーム画面から起動したアプリでも一度ログインしてください）

> クラウドに保存されますが、念のため定期的に JSON エクスポートでバックアップを取ることをおすすめします。
